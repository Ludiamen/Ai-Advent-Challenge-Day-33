## Уточнения проверки после аудита — 2026-10-12

- Полный безопасный прогон: `.venv/bin/python -B run_tests.py`, пять модулей
  включая регрессии HTTP, Telegram security, SSE/startup и offset.
  Контрольный результат `0fc174f`: 1163 теста, 1160 успешно, 3 пропущено.
- Для production polling проверять завершение предыдущего update до следующего,
  ошибку окончательной доставки и аварии checkpoint, а не только постановку
  в очередь. Checkpoint — числовые метаданные, без текстов.
- Допустим повторный ответ после аварии между доставкой и фиксацией checkpoint.
  `/status`, `/start`, `/help` владельца — сразу, во время генерации (версия 2:
  решение владельца, проверяется тестами `МгновенныеКоманды`).
- Прогоны с настоящими Telegram, Ollama, HTTPS, Docker и systemd — отдельные
  интеграционные испытания; исторические протоколы не заменяют свежую приёмку.

Актуальный безопасный runner после шести новых регрессий тестового окружения:
1169 тестов, 1166 успешно, 3 пропущено, 0 ошибок. Числа 1163/1160/3 выше —
контрольный результат коммита `0fc174f`, до добавления этих регрессий.
